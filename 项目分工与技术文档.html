一、项目概述

本项目实现了一个能调用工具干活的 AI 智能体框架：用户的提问由远端大模型（Qwen）负责思考与决策，本地只负责执行工具（计算、联网、读写文件、代码运行等）。

核心特性

  • ReAct 闭环：思考 → 调工具 → 观察结果 → 继续思考 → 最终回答
  • 零本地算力：所有智能来自云端 LLM，本地只执行工具
  • 零第三方依赖：仅用 Python 3.9+ 标准库，拿到就能跑
  • 18+ 内置工具：计算、搜索、文件、代码、知识库、记忆、多模态等
  • 现代化 Web 界面：三栏布局、流式输出、工具调用可视化

技术说明

text-embedding-v3向量嵌入，用于知识库 RAG

前端技术

技术说明

原生 JavaScript无 jQuery / 无 React
EventSource API浏览器端 SSE 流式接收
响应式设计桌面 + 手机自适应

存储与数据

技术说明
SQLite长期记忆（用户偏好 + 事实存储）
JSON 文件知识库向量数据、用量统计历史

三、核心知识点

3.1 Agent 架构基础

知识点说明对应模块
ReAct 模式Reasoning + Acting 交替进行agent/core.py
感知-决策-执行三层架构：输入 → 思考 → 行动agent/core.py
函数调用（Function Calling）LLM 输出工具名 + 参数，本地执行llm/base.py
工具注册表模式统一管理工具的注册、列举、执行tools/registry.py

3.2 记忆系统

知识点说明对应模块
短期记忆对话上下文，token 滑动窗口裁剪agent/memory.py
长期记忆跨会话持久化，用户偏好 + 事实agent/long_term_memory.py
自动记忆提取LLM 自动从对话中提取值得记住的信息agent/memory_extractor.py
用户画像偏好注入 system prompt，个性化回答agent/core.py

3.3 知识库 RAG

知识点说明对应模块
RAG（检索增强生成）先检索相关文档，再拼入 Promptagent/rag.py
文档切分按段落/句子切分，带重叠agent/rag.py
向量嵌入（Embedding）文本转成稠密向量llm/embedding.py
余弦相似度检索计算向量相似度，取 top-kagent/rag.py

3.4 智能增强

知识点说明对应模块
任务规划复杂任务拆解成步骤计划agent/planner.py
自我反思工具失败后回传 LLM 自动调整agent/core.py
自动重试网络错误类工具自动重试agent/core.py
遥测与成本统计token 计数、费用估算、运行日志agent/telemetry.py

3.5 高级能力

知识点说明对应模块
多Agent协作主管-员工模式，任务分配与汇总agent/multi_agent.py
工作流编排多步骤批量执行，变量引用tools/workflow.py
多模态图像理解（Qwen-VL）、文生图tools/multimodal.py
代码执行Python / Shell 执行 + 授权机制tools/executor.py

3.6 安全设计

知识点说明对应模块
AST 白名单计算器只允许数学运算，防代码注入tools/builtin.py
路径沙箱文件工具只能访问 workspace/tools/builtin.py
授权机制代码执行需用户确认（ask/auto/off）tools/executor.py
风险黑名单删除、格式化、关机等高危操作拦截tools/executor.py

五、协作流程

开发顺序

第一周：核心引擎 + 基础工具（A + B）
   ↓
第二周：智能增强（C）
   ↓
第三周：高级能力（D）
   ↓
第四周：前端 + 集成测试（E + 全员）

Git 协作

  • 每人一个 feature 分支，开发完合并到 main
  • 提交信息规范：feat: 新增功能 / fix: 修复bug / docs: 文档更新
  • 每天至少 push 一次，避免代码丢失

接口约定

  • 模块之间通过抽象接口解耦（如 LLMClient、Tool、Agent）
  • 新增工具继承 Tool 基类，注册到 ToolRegistry 即可
  • 新增 LLM 后端继承 LLMClient 即可切换
